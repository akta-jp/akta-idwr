# akta 感染症ダッシュボード（ベータ）

HIV / 梅毒 / A型肝炎 / エムポックス の週ごとの報告数を、全国と東京都で表示するダッシュボードです。
データは国が毎週公表している **IDWR速報（全数把握疾患CSV）** から自動取得します。

## 仕組み

```
GitHub Actions（毎週火曜）
  → IDWR速報CSVを取得（Shift-JIS → UTF-8）
  → HIV/梅毒/A型肝炎/エムポックス × 全国・東京都 を抽出
  → data.json を更新してコミット
       ↓
GitHub Pages が data.json を配信（CORS許可あり）
       ↓
akta.jp の「カスタムHTML」ブロックが data.json を読んで描画
```

WordPress側にはPHPもプラグインも追加しません。壊れる箇所を最小にしてあります。

## ファイル

| ファイル | 役割 |
|---|---|
| `fetch_idwr.py` | CSV取得・パース・`data.json` 生成 |
| `.github/workflows/update-idwr.yml` | 毎週火曜の自動更新 |
| `akta-idwr-embed.html` | WordPressに貼る本体（HTML+CSS+JS、外部ライブラリなし） |
| `preview.html` | デモデータ入りのプレビュー。ブラウザで開くだけ |
| `data.sample.json` | プレビュー用のダミーデータ（実データではありません） |
| `test_parse.py` | パーサの自己テスト |
| `index.html` | GitHub Pagesで単体表示するページ（iframe設置用の保険） |
| `DEPLOY.md` | ブラウザだけで公開する手順書 |

## 立ち上げ手順

> **ターミナルを使いたくない場合は `DEPLOY.md` を見てください。全部ブラウザで完結する手順を書いています。**


1. このフォルダをGitHubリポジトリにpush（publicにする）
2. 初回だけ手元で総ざらい：
   ```bash
   # 今年＋過去5年（カードの PAST_YEARS=5 に対応）
   python3 fetch_idwr.py --past-years 5 --out data.json
   git add data.json && git commit -m "data: initial backfill" && git push
   ```
   年を直接指定したい場合は `--years 2024 2025 2026`。2022年以前も同じコマンドで取れます（URL体系の切替は自動）。1週ごとに1秒空けるので、6年分で5分ほどかかります。
3. リポジトリの **Settings → Pages** で `main` ブランチのルートを公開
   → `https://<ユーザー名>.github.io/<リポジトリ名>/data.json` が生える
4. **Actions → Update IDWR data → Run workflow** を一度手で押して動作確認
5. `akta-idwr-embed.html` の1行目付近、`data-src` を4のURLに書き換える
6. akta.jp の固定ページを新規作成 →「カスタムHTML」ブロック → ファイルの中身を全部貼り付け → プレビューで確認 → 公開

以降は毎週火曜に自動更新されます。WordPress側は何もしません。

## 中身を変えたいとき

- **表示する疾患を足す**：`fetch_idwr.py` の `TARGETS` に疾患名を追加し、`akta-idwr-embed.html` の `META` と `ORDER` にも追加。全数把握疾患ならすべて同じCSVに入っています。
- **カードの一言コメント**：`META` の `note` を書き換え。ここはaktaのメッセージングの領域なので、公開前に必ず見直してください。
- **但し書き**：`META` の `caveat`。HIVカードに「後天性免疫不全症候群としての届出であり、HIV感染者とAIDS患者の合計」という注記を入れています。**これは消さないでください**（後述）。
- **表示する期間**：`SPAN`（既定52週）を変更。
- **並置する過去年数**：`PAST_YEARS`（既定5年）を変更。データの無い年は自動的に飛ばすので、増やしても壊れません。ただし表示させたい年数ぶんのバックフィルが `data.json` に入っている必要があります（下記）。

## 設計上の注意（触る前に読む）

- **URL体系が2023年で分断されています。** JIHSサイトの速報CSVは、2023年第1週を境に2系統に分かれています。

  | 期間 | URL |
  |---|---|
  | 2023年第1週 〜 現在 | `/surveillance/idwr/provisional/{年}/{週}/{年}-{週}-zensu.csv` |
  | 2012年第37週 〜 2022年第52週 | `/niid/images/idwr/sokuho/idwr-{年}/{年}{週}/{年}-{週}-zensu.csv` |

  旧系統はディレクトリ名が `202242` のように年と週の連結である点に注意（新系統は `/2022/42/`）。両系統とも週番号は2桁ゼロ埋め、中身はShift-JIS、ヘッダー構造・列構成・疾患名の表記はすべて同一なので、パーサは共通で通ります。`fetch_idwr.py` の `build_url()` が年で自動的に切り替えます。**片方の系統だけを見る実装に戻さないでください。過去分が例外も出さずに丸ごと欠落します。**

  収録の最古は **2012年第37週**（2012年第36週は404）。`EARLIEST` でガードしてあるので、それより前は最初からリクエストしません。

- CSVは **Shift-JIS**。UTF-8で読むと必ず文字化けします。
- ヘッダーは3行構造で、**列の位置は年度によってずれます**。疾患名で列を探す実装にしてあるので、列番号でのハードコードに戻さないでください。
- 「A型肝炎」は全角Ａで入ることがあります。NFKC正規化で吸収しています。
- 「エムポックス」は2023年の改称前は「サル痘」。過去データ用に両方を照合しています。
- **HIVはIDWR上「後天性免疫不全症候群」という1カテゴリ**で、無症候性キャリアとAIDS患者の合算です。IDWR週報では内訳が取れません。内訳・確定値は厚労省エイズ動向委員会の四半期／年次報告が正本です。カードのcaveat表記を外すと、この数字が「新規HIV感染者数」として独り歩きします。
- **掲載値は速報値**です。後日修正されます。フッターの注記は消さないでください。直近4週は毎回取り直して修正を取り込みます。
- 出典表記（JIHS感染症情報提供サイトへのリンク）はフッターに常時表示しています。公開前にJIHSの利用規約を一度確認してください。

## 次の段階（フェーズ2）

- **エイズ動向委員会の四半期報告**を並置すると、HIVカードの内訳（HIV感染者／AIDS患者、いわゆる「いきなりエイズ」割合）まで出せます。週次ではないので別レイアウトになりますが、aktaが出す意味はここに一番あります。
- **東京都の週報**を足すと、保健所別・年齢別・性別の粒度が出せます。ただし都の「WEB感染症発生動向調査」はフォーム経由のCSV出力なので、自動化の難易度は一段上がります。まずこのベータを走らせてからで十分です。
- 新宿区の数字が出せるようになると、このダッシュボードの意味が変わります。
